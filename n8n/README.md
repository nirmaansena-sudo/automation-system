# n8n workflows (the visual, editable layer)

The backend works on its own. n8n adds a visual layer you can change without code:
AI understanding, the daily/monthly schedule, email/Sheets/CRM integrations,
error alerts and a watchdog that checks the backend every 15 minutes.

| File | What it does | Needs |
|---|---|---|
| `01-ai-understanding.json` | Backend asks n8n to read a WhatsApp message with your AI model (OpenAI-compatible API). Returns JSON only — never writes to clients. | `AI_MODE=n8n` in the backend, AI key in n8n |
| `02-scheduled-routines.json` | 8 schedules (morning brief, hourly missing-check-in checks, evening attendance, payment reminders, lead follow-ups, 7 PM client update, backup, monthly payroll). Each calls the backend. | `ROUTINES_MODE=n8n` in the backend |
| `03-business-events.json` | Receives events (new enquiry, visit confirmed, project created, payment, ticket…). Email / Google Sheets / CRM examples included (disabled until you add credentials). | `N8N_BASE_URL` in the backend |
| `04-error-alerts.json` | When any workflow fails → alert in the dashboard bell (+ email once enabled). | Set as *Error workflow* in each workflow's settings |
| `05-health-watchdog.json` | Every 15 min checks the backend's health; emails you if it is down or unhealthy (enable the email node). | — |

## 1. Start n8n with the right settings

**On your Windows PC (testing):** double-click `start-n8n-windows.bat` in the main folder.
It runs `npx n8n` with these environment variables (taken from the backend's `data/secrets.json`):

```
GENERIC_TIMEZONE=Asia/Kolkata
N8N_BLOCK_ENV_ACCESS_IN_NODE=false     # lets workflows read the NS_* settings below
NS_BACKEND_URL=http://localhost:3000
NS_AUTOMATION_KEY=<automation key from Settings → Connections>
NS_N8N_SECRET=<shared secret from Settings → Connections>
NS_AI_BASE_URL=https://api.openai.com/v1   # or any OpenAI-compatible endpoint
NS_AI_API_KEY=<your AI key>                # only for workflow 01
NS_AI_MODEL=<model name>                   # only for workflow 01
```

**On the server:** `docker-compose.yml` already starts n8n with these variables.

## 2. Import

n8n → **Workflows → ⋯ → Import from file** → choose each JSON file in `n8n/workflows`.
Then in each workflow: open it, check the sticky note, and click **Publish** (n8n 2.x)
or switch it **Active** (n8n 1.x).

## 3. Connect the backend to n8n

In the backend `.env` (main folder), set and restart:

```
N8N_BASE_URL=http://localhost:5678        # in Docker: http://n8n:5678
ROUTINES_MODE=n8n                          # n8n runs the schedule; backend steps in if a run is missed
AI_MODE=n8n                                # optional: use workflow 01 for AI
```

## 4. Optional integrations

* **Email:** create an SMTP credential (e.g. a Gmail app password), select it in the
  disabled *Email the owner* nodes, enable them.
* **Google Sheets:** the simplest reliable way is a Google Apps Script web app that
  appends rows; paste its URL in *Send to your sheet / CRM* and enable it.
* **Error workflow:** in workflows 01, 02, 03, 05 open *Settings → Error workflow* and pick
  *NS 04 · Error alerts*.

## Safety rules built in

* Every call from the backend carries `X-NS-Secret`; workflows reject anything else.
* Every call to the backend carries `X-Automation-Key`; the backend rejects anything else.
* A routine triggered twice in the same period runs once (the backend keeps a run key).
* If n8n is stopped, nothing breaks: the backend runs any missed routine 20 minutes late
  and shows a warning in the dashboard.

The JSON files are generated by `scripts/build-n8n.py` and checked by `npm run check`.
